# project-react-fth

Repository ini merupakan project React JS untuk Mata Kuliah Pemprograman Sisi Klien.

## Basic setup

### Prasyarat
- Node.js 20+ (disarankan LTS)

### Instalasi
```bash
npm install
```

### Menjalankan project (development)
```bash
npm run dev
```

### Build production
```bash
npm run build
```

### Lint
```bash
npm run lint
```
